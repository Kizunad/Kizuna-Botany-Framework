# Kizuna's Botany Framework

独立的 Minecraft Fabric 植物表现库，目标环境为 Minecraft 1.20.1、Java 17。

服务端通过版本化请求驱动植物模型、阶段、粒子、声音、发光和缠绕表现。服务端继续拥有生长、接触判定、伤害、真元、Buff 和采集等玩法规则。

当前正在从 Bong 提取 47 种植物的表现代码和资源。本阶段不包含 Harvest 小游戏和季节状态。独立 Jar 尚在迁移和验证中，暂未发布可用版本。
